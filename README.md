
# Password-manager
In this project, we'll be building a Graphical User Interface(GUI) Password Manager application that will help us manage,store our retrieve their passwords easily.The passwords will be encrypted and stored in a SQLite database.

## Technical Requirements:
Python 3.10 | 
SQLite3 - Local database | 
hashlib - Master password hashing |
Cryptography (Python) library |
Tkinter (Python) | VS Code or another Python IDE

## Installation
Clone the repository
```
git clone <repository-url>
```
Install Dependencies
```
pip install -r requirements.txt
```
For Run
```python
python main.py
